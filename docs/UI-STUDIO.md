# Anything Studio · 个人收集室

桌面与浏览器扩展采用「把发现，留在身边」的方向：把下载作为收集过程，把文件作为界面的主体。此文替代 `UI-DESIGN.md` 中的视觉定义，既有操作保护与交互约束继续适用。

## 视觉语言

- 暖纸色背景、墨绿正文、淡青柠色主入口。语义色只用于状态、反馈和文件类型。
- 中文标题使用本地宋体 / 衬线字体，内容使用系统无衬线字体，数字和索引使用等宽字体。字体、图标、插画均离线可用。
- 使用留白、细分隔线和目录编号组织界面；文件类型以柔和色签呈现。
- 深色模式跟随系统，使用深绿纸面和浅墨色文字。

## 布局与操作

顶部为品牌与工作空间，右侧保留导入、导出和设置。链接输入位于主标题下，提交后带入新建面板，保留多链接、保存目录、命名、校验和镜像功能；校验与镜像默认折叠。

「我的收藏」包含搜索、状态页签、类型筛选和排序。目录行保留来源、状态、速度、进度和状态对应的操作。点击文件名或双击行进入详情；复选框支持 Shift 范围选择和批量操作。

空收藏保留完整的欢迎标题；有任务后自动收紧标题区域，把空间交给目录。文件名使用 13px、状态和来源使用 11px 字号。1280×820 窗口可显示约五条完整记录。

设置面板的标题和保存操作保持可见，只有字段区域滚动。保存期间禁用关闭和重复提交。已配置字段清空时提交空值，读取设置时包含完成后动作、剪贴板监视与 yt-dlp 路径。

右侧「传输现场」显示引擎提供的实际速度，每秒采样，记录最近 40 秒。下方为类型索引和已完成记录的总大小。统计来自实际任务，不注入演示任务。暂停/继续按钮根据活跃、暂停任务数量启用。

空列表、搜索无结果和筛选无结果分别提供对应出口。浏览器打开时明确显示预览模式，可查看新建界面；依赖本地能力的操作给出桌面应用提示。

## 实现约束

- 保留 Tauri 命令接口、下载引擎、增量轮询和事件更新流程。
- 虚拟滚动与任务行共享 `ui/src/const.ts` 中的 80px 行高。容器通过 ResizeObserver 观测尺寸，筛选和排序时重置滚动位置。
- 普通进度事件保持列表快照引用稳定，只有对应任务行更新；任务元数据和状态变化时重建列表。速度排序以 500ms 周期刷新，汇总速度不变时也能反映任务间的速度变化。
- 暂停时保留最新实时进度；增量轮询收到结束状态时清理旧速度。侧栏的分类和完成统计只在列表数据变化时重新计算。
- 支持 860×540 桌面最小窗口，矮窗口压缩标题区域；更窄的浏览器预览隐藏侧栏。
- 保留删除确认、未保存修改确认、操作失败反馈、焦点环和减少动画设置。
- Ctrl/Cmd+K 聚焦搜索；Ctrl/Cmd+N 打开新建；Esc 关闭浮层或清除选择。

## 验证

使用 TypeScript 检查和 Vite 生产构建验证。浏览器交互检查通过模拟 Tauri 接口覆盖筛选、搜索、排序、选择、新建、详情、设置、导出及一万条记录的虚拟滚动；截图检查覆盖亮暗模式、中英文、桌面最小窗口和窄屏预览。模拟数据仅存在于本地验证脚本中，不进入产品。

`npm --prefix ui run test:store` 运行五项状态与性能回归测试，覆盖一万条任务连续更新、总大小更新、暂停进度保留、漏掉事件后的轮询恢复和删除任务的迟到事件。

## 离线预览

先执行 `npm --prefix ui run build`，再执行 `npm --prefix ui run export:preview`。生成 `.smoke/anything-studio-preview.html`，JavaScript 与样式均内嵌，可断网直接打开，无需本地开发服务。预览保留新建面板和键盘操作，实际下载仍由桌面应用完成。

## 浏览器收集室

扩展无需构建，重新加载 `extension/` 即可使用。`studio.css` 提供公共色板、字体、品牌标记及亮暗主题，`popup.css` 和 `sync.css` 分别处理弹窗与工作台。图标源文件为 `branding/ad-logo-source.png`，各尺寸 PNG 随扩展一起提供。

- 工具栏弹窗固定为 440×600，头部、链接输入和底部下载接管开关保留，资源列表在中间独立滚动。资源按纸签式文件图标、名称、来源、类型和大小呈现，支持原有筛选、清晰度选择、复制与批量推送。
- 「本页发现」与「传输现场」通过下划线页签切换；连接标记来自真实主程序检查，未连接时提供指引。新增的文章工作台入口打开既有扩展选项页。
- 「收集偏好」作为独立面板展开，关闭后恢复焦点，Tab 不离开面板，Esc 关闭。资源类型和适配器分组展示；配置与下载接管开关即时保存到原有 storage 键。
- 网页浮标采用纸签图标，面板保留 closed Shadow DOM 和构造式样式表，避免宿主页样式或 CSP 破坏布局。文章工具用编号目录组织，资源勾选和收集按钮保持原有功能。
- 文章工作台采用编辑区与目标栏并列布局，保留文章提取、Markdown 编辑、平台选择、默认草稿、登录检测、账号管理和同步历史。窄屏转为单列，正文字符数即时显示。
- 文章摘要与 Markdown 编辑等网页弹层同步使用纸色与墨绿主题，支持键盘关闭和焦点循环。导出的 PDF、Word、海报内容模板保持原有格式。

浏览器交互验证通过模拟 Chrome 通信与平台接口覆盖弹窗、偏好、离线指引、文章工作台和闭合 Shadow DOM 面板；未向真实站点发布内容。适配器、文章、视频号、库及同步相关的 470 项既有测试通过。
