# Anything Downloader · 下载管理界面

桌面应用以下载任务为主体，取代「个人收集室」的布局与文案。本文为桌面端当前设计依据；历史 Studio 文档中的扩展工作流仍保留。

## 布局

- 左侧导航：全部下载、正在下载、排队与重试、已暂停、已完成、下载失败、已取消，分别显示真实任务数。「正在下载」包含探测、合并、校验、解密等处理阶段；行内显示准确状态。
- 顶部：当前任务视图、文件名和链接搜索。保留已有的文章正文命中能力。
- 链接输入：粘贴 HTTP / HTTPS 链接后点击「立即下载」，使用引擎的默认保存目录；多个链接可用空格或换行粘贴。提交期间禁用重复提交，部分失败保留失败链接并反馈原因；成功添加后回到全部下载，便于看到新任务。
- 「新建下载」和「更多下载选项」打开完整面板，保留批量链接、自定义目录、命名、校验与镜像。
- 任务工具栏：全部暂停、全部恢复，完成视图的清空记录，失败视图的全部重试，以及导入、导出、类型筛选和排序。类型筛选只保留一处。
- 任务列表：文件名、来源、准确状态、进度和已下载大小、实时速度、预计剩余时间及状态对应的操作。完成后可直接打开文件或所在文件夹。
- 底部状态栏：总下载速度、最近 40 秒的实际速度趋势、活跃任务数及完成统计。HLS 总量采用分片计数，不参与字节总量展示，也不据此估计剩余时间。

没有任务时显示「还没有下载任务」及新建入口；搜索无结果和筛选无结果分别提供清除入口。所有文案使用下载、任务、保存目录等明确术语。

## 适配与交互

使用深蓝导航、浅灰工作区、白色任务列表和蓝色主操作；深色模式跟随系统。采用本地系统字体和 SVG 图标，无外部字体和图片依赖。

桌面最小窗口为 860×540，该尺寸保留任务进度、速度和行内操作；较窄窗口隐藏剩余时间。窄屏预览使用带可访问名称的图标导航，进一步收紧任务列。下载列表独立滚动，工具栏和底部状态保持可见。

任务行高统一由 `ui/src/const.ts` 定义为 72px。虚拟滚动保留万级任务支持。Shift 范围选择、全选与部分选中状态、批量操作、快捷键、浮层焦点管理、删除确认及未保存修改确认继续适用。

快捷键：Ctrl/Cmd+N 新建下载，Ctrl/Cmd+K 搜索，Esc 关闭浮层或清除选择。

浏览器环境明确显示「界面预览」，允许查看新建面板；实际下载和本地文件操作由桌面应用提供。

## 验证

基础检查：TypeScript 类型检查、`npm --prefix ui run build`、`npm --prefix ui run test:store`。

浏览器交互使用模拟 Tauri 接口验证状态导航、搜索、类型与排序、范围选择、新建下载、快速下载、参数面板、详情、设置和导出。视觉检查覆盖 1280×820、1080×720、860×540、窄屏、中英文及系统深色模式。模拟任务只存在于验证脚本，不进入产品。

先启动 Vite 开发服务器，再在提供 Playwright 和 Microsoft Edge 的环境执行 `npm --prefix ui run test:ui`。`UI_TEST_URL` 可指定开发服务器地址（默认 `http://127.0.0.1:5173/`），`PLAYWRIGHT_MODULE` 可指定已有 Playwright 安装位置。截图写入 `.smoke/downloads/`。
